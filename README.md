# Final Year Project: JASP - Balochi Literature & Q&A Platform

## Description
JASP is a dedicated web application designed to serve as a hub for Balochi literature, insights, and community discussions. Modeled after Q&A platforms like Quora, it allows users to ask questions, write rich-text posts (such as poetry, stories, or articles), and engage with content through upvotes and comments.

The platform solves the problem of scattered Balochi literary resources by providing a centralized, interactive space for students and enthusiasts. Key features include a multi-language interface (English & Balochi), a Topic Following system, Guest Mode for public access, and real-time feed updates.

## Technologies
The project is built using a modern, scalable tech stack:

* **Framework:** Next.js 15 (App Router)
* **Language:** TypeScript
* **Styling:** Tailwind CSS
* **Backend & Database:** Supabase (PostgreSQL)
* **Authentication:** Supabase Auth (Email, Google, GitHub)
* **Realtime Features:** Supabase Realtime (Live feed updates)
* **Icons:** Lucide React
